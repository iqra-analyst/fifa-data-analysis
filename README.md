# FIFA Data Analysis 🎮

## About
Analyzed the FIFA player dataset containing 77 columns of player statistics, wages, ratings and nationalities.

## What I did
- Cleaned messy raw data (currency strings, missing values, 
  mixed data types)
- Performed exploratory data analysis using Pandas
- Created visualizations using Matplotlib
- Extracted insights on player wages, ratings and value

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Lab

## Key Finding
Players with higher overall ratings generally earn higher wages,however some highly rated players are significantly underpaid —making them potentially valuable transfers for clubs.
